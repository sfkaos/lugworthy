# 12 Admin CMS — Lugworthy (lugworthy.com)
Roles: admin (all), editor (content, review queue), brand (own brand only via /dashboard).
Screens:
- Brands: list/filter by status, claim, license, sync health; edit all fields; send invite; manual verify.
- Models/variants: edit specs with provenance, lock fields, merge duplicates, publish toggle.
- Review queue: new imports and changes (diff view, approve/reject/bulk).
- Media: rights status, alt text, reorder, set banner focal point.
- Calibers: master list + aliases.
- Videos: add by URL, series, tag brands/models/timestamps.
- Editorial: block editor with model/video card embeds, preview, schedule.
- Sync: runs log, errors, "sync now", per-brand pause.
- Affiliates: per-brand program config and link test.
- Audit log of all edits (who, what, when).
