# 05 Page specs — Lugworthy (lugworthy.com)
Every page: loading = skeletons matching layout; error = message + retry + link home; empty = helpful next step (never blank).

## Home
Purpose: start searching. Sections: Search + chips; New releases (12 ModelCards); Featured brand (themed BrandHero mini); Latest En Punto video (1 VideoCard); Browse by style tiles; New brands; Newsletter.
```
[Search............................][Go]
[<$500][38mm][Diver][NH35][Ships US]
New releases  > [card][card][card][card]
Featured brand: [banner/logo/color | story | 3 models]
Latest video [thumb ▶]  Browse by style [Diver][Field][GMT][Dress]
```

## Browse / Filter (/relojes)
Sections: FilterRail (P0 open), ActiveFilterChips, count + sort, ModelCard grid (24/page, infinite or paginated), 1 VideoCard max per 12, CompareTray. Mobile: filters in bottom sheet. Empty: "No matches" + remove-last-filter suggestions.
```
[Filters    ] 1,284 watches   Sort[Newest]
[Price ===o=] [chip x][chip x]
[Size 36-40 ] [card][card][card][card]
[Movement   ] [card][card][▶video][card]
[...more    ] [Compare tray: A B + Compare]
```

## Brand detail
Sections: BrandHero (banner, logo, colors, country, founded, price range, badges), Story, Collections tabs, All models grid + in-brand filters, Spec summary, En Punto videos, Where to buy, Claim status ("Unclaimed—are you this brand?").
```
[=========== BRAND BANNER (brand colors) ===========]
[logo] Brand · Mexico · since 2019 · $–$ [En Punto]
Story ................
[Collections: All | Diver | Field]
[model][model][model][model]
Specs summary | Videos [▶][▶] | Where to buy
```
Unclaimed + no license: text specs, neutral theme, placeholder silhouette image, link to brand.

## Model detail
Sections: Gallery; title, price (USD; brand currency on hover), stock, VariantPicker; BuyButton + Add to compare; SpecTable (all groups); Related videos (timestamped); More from brand; Similar (spec similarity).
```
[gallery        ] Brand / Model Ref
[thumbs.....    ] price · In stock
                  [dial swatches][strap]
                  [Buy at brand ↗][+Compare]
Specs: Case | Movement | Dial | ...
Videos: [▶ 03:12 seen here]
```

## Compare
Columns 2–4, sticky header with image/name/price/buy; rows grouped; "Only differences"; CaseOutline overlay. Empty: pick from recent/popular.

## Videos hub / video page
Hub: series rows of VideoCards with brand/model chips. Video page: embed, title, description, chapters (timestamp → model link), featured watches grid, related videos.

## Editorial
List with filters (guides, round-ups, fair coverage). Article: rich text with embedded ModelCards/VideoCards that pull live data.

## Brand index, caliber/style/country hubs
Grid + facet filters; hub intro copy for SEO.

## For brands / claim / panel
Explainer, benefits, image policy, Claim CTA; claim steps (08); panel: profile, theme, models, images, license, sync log.
