# 08 Brand opt-in and claim flow — Lugworthy (lugworthy.com)
1. Draft: ingested brand is private (status=draft) or public text-only (admin choice) with neutral theme and no brand images.
2. Invite: admin sends invite (email/DM template) with tokenized link /claim/[token]. Brands can also self-start from /for-brands.
3. Verify (one of): email at the brand's website domain (magic link); meta tag `<meta name="lugworthy-verify" content="TOKEN">` on homepage; DNS TXT; manual admin approval (e.g. met at En Punto).
4. Image license: plain-language checkbox: non-exclusive, royalty-free, revocable permission to display brand images on the Lugworthy and related En Punto social posts with credit; versioned; logs user, time, IP.
5. Onboarding: confirm profile, upload logo/banner, pick colors (live contrast check), review each model's specs (diff vs imported), choose public models, set affiliate program if any.
6. Publish: brand set published, claim_status=claimed, Verified badge.
7. Ongoing: panel shows sync log and pending changes; brand can revoke license (images hidden ≤1h) or request removal (takedown within 48h).
Takedown/DMCA form in footer for anyone.
